# 國際照顧備援／緊急計畫工具比較

最後更新：2026-08-22

## 研究目的

本文件不是為了複製國外工具，而是拆解成熟的 caregiver contingency / emergency planning 做法，判斷：

1. 哪些資料與流程已被多個成熟工具反覆採用，可作為備份心的基礎；
2. 哪些做法需要依台灣長照制度調整；
3. 哪些問題現有工具處理不足，可能形成備份心真正的產品缺口。

---

## 1. Family Caregiver Alliance（美國）— Backup Planning

### 核心問題

FCA 直接以「如果照顧者突然不在，接受照顧的人怎麼辦？」作為備援規劃切入點。

### 主要做法

- 先辨識可能的 backup caregiver
- 主動與對方討論需要什麼協助以及是否願意接手
- 不只依賴單一親友，可由家人、朋友與 homecare agency 組成照顧團隊
- 為接手者準備 emergency how-to guide
- 集中保存重要聯絡人、健康狀況、用藥、每日作息、固定行程與生活偏好等資訊

### 對備份心的意義

**分類：B｜調整採用**

可支持：

- 「可能的人」不能直接等於「已確認的人」
- 備援可以由多個人與正式服務共同組成，而不是一定要找到一位完整取代主要照顧者的人
- 接手能力除了「人存在」之外，也涉及資訊能否交接

備份心可以進一步做的是：把「誰可能接手」拆到具體照顧工作與時間，而不是只建立一份整體 backup caregiver 名單。

來源：
https://www.caregiver.org/resource/smart-caregiving-by-fca-backup-planning/

## 2. Carers UK — MyBackUp / Contingency Planning

### 核心做法

Carers UK 建議照顧者預先建立 contingency / emergency plan，並提供 MyBackUp 互動式工具。

其公開指引建議整理的資訊包含：

- 被照顧者基本聯絡資料
- 緊急時希望聯絡的人（家人、朋友、專業人員）
- 用藥及藥物存放位置
- 持續治療需求
- 過敏資訊
- GP／藥局
- 現有照顧與支持服務
- 失禁用品與供應資訊
- 行動困難與輔具（例如輪椅、移位設備）
- 接手者需要知道的行為相關資訊

### 很重要的流程原則

Carers UK 同時建議：

- 與被照顧者討論計畫（若情況允許）
- 與被列為緊急聯絡人的人討論
- 將計畫提供給可信任的人或相關專業人員
- 定期檢查並更新資訊
- 如果家庭／朋友安排失敗，應考慮正式社會照顧或醫療服務

部分地區另有 carer emergency card / emergency care scheme：預先登記緊急計畫，事件發生時可依計畫聯絡親友或安排專業替代照顧。

### 對備份心的意義

**分類：A/B｜成熟原則直接採用、流程依台灣調整**

值得保留：

- 預先建立計畫
- 資料集中但定期更新
- 分享需有意識且針對可信任／相關的人
- 正式服務應是備援網的一部分

不能直接照搬：

- 英國地方政府 emergency duty team、emergency card scheme 等制度並不等於台灣長照制度

來源：
https://www.carersuk.org/help-and-advice/practical-support/getting-help-in-an-emergency/
https://carersdigital.org/mybackup/

## 3. Ontario Caregiver Organization（加拿大）— Contingency & Emergency Planning Toolkits

### 現況

OCO 目前同時提供：

- Contingency Planning Toolkit for Caregivers
- Emergency Planning Toolkit for Caregivers
- Healthcare Journey Binder

2026 年仍持續以 webinar 教導照顧者如何建立及啟動 backup plan，顯示這不是過時概念，而是目前仍在使用的 caregiver support practice。

### 公開資訊顯示的資料類型

工具協助整理：

- medical history
- emergency contacts
- food preferences
- 其他緊急／照顧相關重要資訊

### 對備份心的意義

**分類：B｜調整採用**

值得研究的不只是「填哪些欄位」，還有 contingency plan 與 emergency information 的區分：

- 一份偏向「如果照顧者不能照顧，替代安排是什麼」
- 一份偏向「事件發生時，接手者需要立即知道什麼」

這提示備份心未來可能需要區分：

1. **備援計畫（誰／服務如何承接）**
2. **必要交接資訊（接手後需要知道什麼）**

不應把所有資料混成一份很長的表單。

來源：
https://ontariocaregiver.ca/managing-care/contingency/
https://ontariocaregiver.ca/managing-care/toolkits/
https://ontariocaregiver.ca/webinars/plan-for-the-unexpected-build-your-emergency-and-contingency-toolkit/

## 4. Carers First / NHS England 相關實務（英國）

英國照顧者支持實務已將 carer contingency planning 視為可由健康與社會照顧體系協助推動的工作。

Carers First 的 emergency planning 經驗指出，照顧者建立計畫的障礙包括：

- 不理解 emergency plan 是什麼
- 不知道為什麼需要
- 不知道從哪裡開始

因此其做法不是只告訴使用者「你應該做計畫」，而是提供實際模板與引導。

### 對備份心的意義

**分類：A/B**

這直接支持目前「一頁一題 + `？` 解釋」的 UX 方向。

如果使用者連「為什麼需要備援」都還沒有概念，一開始就要求輸入大量醫療、家庭、人力資料，很可能造成退出。

備份心 onboarding 應先回答：

> 為什麼我要準備這些？

再開始資料盤點。

來源：
Carers UK / integrated system working guidance（carer contingency planning good-practice section）

# 跨工具共同元素

目前多個成熟工具反覆出現以下元素：

| 元素 | 是否值得備份心保留 | 判斷 |
|---|---|---|
| 預先思考照顧者不可用情境 | 是 | 核心基礎 |
| 指定可能接手的人 | 是 | 但需進一步確認意願與能力 |
| 緊急聯絡人 | 是 | 不能等同實際照顧承接者 |
| 健康／疾病必要資訊 | 是，但最小化 | 只收接手照顧必要資訊 |
| 用藥資訊 | 是，但需權限 | 與安全交接直接相關 |
| 每日照顧／生活作息 | 是 | 可轉換成照顧工作結構 |
| 現有正式服務 | 是 | 可作備援網的一部分 |
| 行動／移位需求 | 是 | 會影響替代者是否真的具備能力 |
| 生活偏好 | 部分 | 依是否影響安全／照顧品質決定，不全部納入 MVP |
| 計畫分享 | 是 | 必須明確授權 |
| 定期更新 | 是 | 頻率需研究，不任意設定 |

# 現有工具與備份心的差異假設

> **注意：以下目前是產品研究假設，不是已證明的創新性結論。**

第一輪比較發現，成熟 contingency tools 很強於：

- 提醒家庭預先規劃
- 集中緊急資訊
- 建立 backup contacts
- 產生一份 emergency / contingency plan

但目前公開資料中，尚未看到它們明確把家庭的一天拆成：

```text
時間 × 必要照顧工作 × 原負責者 × 替代人／服務 × 確認狀態
```

再模擬主要照顧者離開 24h／72h／7d 後，逐項找出沒有承接的工作。

因此「備份心」值得繼續驗證的產品缺口是：

> **從『建立一份備援資料』進一步走向『模擬照顧結構失去主要照顧者後，具體哪一項必要工作會失去承接』。**

這個差異目前只能稱為 **candidate differentiation（候選差異化）**，在完成更廣泛 App／研究／專利或產品現況搜尋以前，不宣稱為全球首創。

# 對備份心資料設計的第一版推論

## 不要直接照抄國外表單

建議將資料分為三層：

### Layer 1｜中斷模擬所需資料（MVP 核心）

- 必要照顧工作
- 發生時間／頻率
- 目前負責者
- 替代人力／服務
- 替代者能力
- 替代者／服務確認狀態

### Layer 2｜安全交接所需資料

- 必要用藥資訊
- 重要健康／照顧注意事項
- 移位／輔具需求
- 必要專業聯絡資訊

### Layer 3｜提升照顧品質但非中斷判斷核心

- 食物偏好
- 娛樂偏好
- 其他生活習慣

Layer 3 不應因為其他 toolkit 有收集，就全部塞進備份心 MVP。
