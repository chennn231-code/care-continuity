# 備份心｜Research Evidence Map

> 本文件記錄「備份心」的重要研究證據、來源品質、適用性與對產品設計的影響。

最後更新：2026-08-22

## 證據使用分類

- **A｜直接採用**：已有成熟方法，且適合本專題情境。
- **B｜調整採用**：概念有依據，但需要依台灣家庭長照與備份心流程調整。
- **C｜自行提出**：現有方法不足以處理已確認需求，提出 Prototype 方法；必須明確標示尚待驗證。
- **D｜尚待驗證**：目前僅是假設，不能當成研究事實或正式標準。

## 目前可以採用的研究判斷

### 有足夠方向性支持

1. 家庭照顧者應預先思考自己無法提供照顧時的替代安排。
2. 備援計畫需要包含「誰能接手」以及接手者需要知道的必要照顧資訊。
3. 照顧計畫不是一次性文件，照顧需求、人力與服務改變後需要重新確認。
4. 正式服務可以成為家庭備援的一部分，但「可能可用」不能直接視為「已確認承接」。
5. 照顧連續性已有既有研究脈絡，備份心不應任意重新定義。

### 尚不能宣稱

1. 「照顧斷點」目前的 Prototype 定義是國際正式標準。
2. 備份心目前可以預測照顧中斷發生機率。
3. 家庭照顧韌性可以用我們自行設定的總分衡量。
4. 沒有第二照顧者就等於某個固定風險分數。
5. 找到喘息／居服等服務就代表發生事件時一定能立即使用。

## 下一輪研究問題

1. 深入搜尋 caregiver contingency planning 的既有 assessment / worksheet 欄位。
2. 尋找主要照顧者住院、死亡、突然失能後的照顧中斷研究。
3. 釐清 care gap 在 long-term care / informal caregiving 文獻中的既有用法。
4. 深入搜尋 family caregiver resilience 的概念模型與已驗證量表。
5. 查證台灣長照服務申請、喘息、短照、居服等實際銜接流程與限制。
6. 比較台灣與國際現有 App／數位工具，確認備份心真正的產品缺口。

## 研究紀錄原則

- 優先使用官方資料、同行評審研究、systematic/scoping review 與具公信力專業組織。
- 最新資料優先用來確認「目前政策、服務與產品現況」。
- 經典舊研究若仍被後續研究支持，可保留作理論或方法依據。
- 每個產品決策應標記為：有證據直接支持、依證據調整、Prototype 自行提出、或尚待驗證。
- 不因資料年份較新就自動判定品質較高。
