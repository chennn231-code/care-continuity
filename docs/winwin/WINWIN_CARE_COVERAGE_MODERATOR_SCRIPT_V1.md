# WinWin Care Coverage Moderator Script V1

Status: **PILOT MODERATOR SCRIPT — NOT YET EXECUTED**

## 1. Purpose
Provide a consistent read-aloud script for a future separately authorized Pilot-02 using `CC-VAL-PILOT-V4`.

## 2. Moderator Boundary
Test the design, not preference or competence. Do not teach answers, close blockers, claim validation, provide care advice or collect unnecessary personal information.

## 3. Pre-session Preparation
Confirm material versions, assigned B-01 order, participant code, blank record, timer, private setting, hidden answer key, and separate optional recording choice. Record session start time; if missed, write `MISSING` and never reconstruct it.

## 4. Opening Script
「謝謝你參與。這是學生原型研究，我們要測試畫面和文字，不是在考你，也沒有成績。我想知道你第一眼怎麼理解，不用猜我想聽的答案。你可以隨時停止或跳過任何問題。」

## 5. Privacy Reminder
「請不要分享不必要的真實姓名、地址、聯絡方式、病歷、診斷或家庭衝突細節。我會用參與者代碼記錄與產品設計相關的回答。」

## 6. Recording Permission Boundary
「今天用書面筆記就能完成。如果另外希望錄音或錄影，我會先單獨詢問；你不同意也完全不影響參與。」 Never record without separate explicit permission.

## 7. General Question Rules
During the session capture only first interpretation, essential selected response, critical flag, timing and one notable quote when feasible. Use neutral 「為什麼？」「你從哪裡看出來？」「還有其他可能嗎？」「哪個地方讓你這樣理解？」 Complete detailed coding immediately after the block/session from notes or separately authorized recording. Explain only after a block ends.

## 8. Prohibited Leading Language
Never say 「這邊其實是還沒確認」「這應該是下午吧？」「你是不是覺得姐姐還沒答應？」「這應該放移位對不對？」 Do not praise a target answer or reveal enum/answer keys.

## 9. B-01 Script
「接下來有四張照顧安排卡。我會一次給你一張。」 Present assigned order. PRIMARY: 「你怎麼理解現在這項照顧安排的狀態？」 STANDARD: 「你從哪裡看出來？」「你覺得現在還需要確認什麼？」 Use confirmation, nobody-can-care and already-done probes only if needed. For each partial/incorrect response, mark primary confusion source `LABEL`, `EXPLANATION`, `STATE CONCEPT`, or `UNCLEAR`. After B-01 ask whether the participant wants a short break or to continue; do not display later modules yet.

## 10. B-02 Script
「接下來是十個虛構的照顧情境。」 Show one scenario at a time; never provide the complete instrument as one batch. Run separate passes A–D as specified. After B-02 record approximate block timing and ask whether the participant wants a break or to continue.

## 11. B-03 Script
「接下來請看一張有人詢問你是否願意接手一段責任的虛構卡片。先不用選。」 Show only B03-C1 and read all seven questions from Materials §17. Use 「這次不接手」 and 「願意接手」 neutrally and with equal emphasis. After B-03 record approximate block timing and check whether to pause, stop or continue.

## 12. B-04 Script
「這裡有十六張虛構活動卡和一個仍在測試的整理方式。每張先選一個最接近的主要活動類型；情境描述可以不加、加一個或加多個。沒有合適的、需要新的情境、其他或不確定都可以直接說。」 Record first primary choice, first context, additional contexts and reason. `生活安排` and all nine boundary cards are qualitative; never imply the structure or one category is correct. Later report the seven core results as raw numerator/denominator and percentage.

## 13. Data-entry Burden Script
「最後用五個小問題，一次整理一件王奶奶的虛構照顧安排，不必建立完整計畫，也不要使用自己的家庭資料。」 Ask the five prompts from Materials §24 one at a time. Do not provide a completed classification example. Record whether scaffolding is sufficient.

## 14. Debrief
Ask: 「哪個地方最容易誤會？」「哪個詞最難懂？」「你會去哪裡找目前還沒有人確認的時段？」「你會不會把有人確認負責理解成事情已完成？」「資料會不會太多？」「有沒有哪項資料你不希望 App 要求？」

## 15. Closing Script
「今天到這裡，謝謝你。你的回答會用來改善研究材料和產品文字，不會用來作醫療或照顧決定。若剛才有不清楚的內容，我現在可以說明研究想測試的差異。」

## 16. Post-session Recording Rules
Prefer the participant's own spoken or written response. If a facilitator records it, mark each response `VERBATIM`, `NEAR-VERBATIM`, or `FACILITATOR PARAPHRASE`; never silently promote a paraphrase. Immediately after each block/session, complete detailed codes and record order/version, coaching, interruption, approximate block timing and learning effects. Record end time; missed timing is `MISSING`, never reconstructed.

## 17. Critical Incident Handling
If distress, unwanted disclosure or wish to stop occurs, stop the task, avoid probing, remind the participant no explanation is needed, and minimize/delete unnecessary notes according to the study’s approved handling. Record only a bounded process note. Semantic critical errors are logged without correcting until block completion.

Voluntary early stop is valid evidence, never participant failure. Record where the participant stopped, any voluntarily stated reason, and the material/administration conditions immediately before stopping. Never pressure completion.
